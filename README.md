# সিরাজী ফারায়েজ গবেষণা সার্চ

বাংলা ও আরবি প্রশ্ন দিয়ে **নিজের আমদানি করা** কিতাবের পাঠ্য খোঁজার জন্য স্থানীয়, উৎস-প্রথম ওয়েব অ্যাপ। অফলাইনে সার্ভার চালু থাকলেও সার্চ ইঞ্জিন কাজ করে; নতুন অনলাইন কিতাব আনতে আপনার অনুমতিপ্রাপ্ত ফাইল লাগবে।

## চালু করুন

১. এই ফোল্ডারের `run-local.cmd` ফাইলে ডাবল-ক্লিক করুন।

২. ব্রাউজারে [http://127.0.0.1:4181](http://127.0.0.1:4181) খুলুন। অ্যাপের কমান্ড উইন্ডো বন্ধ করতে `Ctrl+C` চাপুন।

Node.js 22.13 বা পরের সংস্করণ প্রয়োজন। আলাদা package download বা `npm install` প্রয়োজন নেই। SQLite, FTS5 সার্চ এবং server Node.js-এর সঙ্গে থাকা বিল্ট-ইন মডিউল ব্যবহার করে। সার্চ ডেটা `data/siraji.sqlite`-এ থাকে।

## নিজের অনুমতিপ্রাপ্ত পাঠ্য আমদানি

`কিতাব যোগ` অংশে `data/admin-token.txt`-এর টোকেন লিখুন, তারপর `.txt`, `.md`, `.html`, `.htm`, `.xml` অথবা JSON ফাইল দিন। ফাইলের সর্বোচ্চ মাপ ৮ MB। Markdown-এর `# শিরোনাম` অধ্যায় হিসেবে ধরা হয়; পৃষ্ঠা নম্বর কেবল আপনি দিলে সংরক্ষিত হয়। PDF-এ embedded text/OCR প্রয়োজন হলে আগে নিজে পাঠ্যে রূপান্তর করে JSON/TXT আমদানি করুন।

JSON কাঠামো:

```json
{
  "book_id": "sirajiyyah-madina-library",
  "passages": [
    {
      "chapter": "باب معرفة الفروض ومستحقيها",
      "page_start": 12,
      "original_text": "অনুমতিপ্রাপ্ত উৎস থেকে হুবহু যাচাইকৃত ইবারত"
    }
  ]
}
```

প্রথম সংস্করণে পূর্বনির্ধারিত কিতাবটি সিরাজিয়্যাহ। নতুন কিতাবের schema বা protected catalogue editor এখনও নেই। JSON-এর `book_id` বিদ্যমান হতে হবে। একই ID দুবার আমদানি হলে তা স্বয়ংক্রিয়ভাবে বাদ যায় না—ফাইল বাছার আগে নকল পৃষ্ঠা পরীক্ষা করুন। আমদানির পর সব বাক্য মানব-যাচাই বাকি; OCR-কে হুবহু উদ্ধৃতি বলে ধরে নেওয়া হয় না।

টোকেনটি কেবল নিজের কম্পিউটারে ব্যবহার করুন; ফাইলটি Git-এ বাদ দেওয়া আছে এবং সার্ভার শুধু `127.0.0.1`-এ শোনে।

## অনুসন্ধান ও উত্তর

* বাংলা/আরবি Unicode, আরবি হরকত, হামজা-আলিফ, অতিরিক্ত স্পেস ও যতিচিহ্ন স্বাভাবিক করে SQLite FTS5-এ খোঁজে। কিতাব ও অধ্যায় ফিল্টার API-তে আছে।
* ফলাফলে হুবহু সংরক্ষিত মূল পাঠ্য, কিতাব, অধ্যায়, পৃষ্ঠা (প্রদত্ত থাকলে), উৎস URL ও যাচাইয়ের অবস্থা থাকে। বাংলা অনুবাদ/ফতোয়া তৈরি হয় না।
* স্থানীয় পাঠ্য না থাকলে `NOT_FOUND` fallback দেয়। দূরবর্তী অনলাইন পাতাকে স্থানীয় সূচি বা যাচাইকৃত উদ্ধৃতি বলে দেখায় না।
* ফারায়েজ ক্যালকুলেটর তথ্য নিতে পারে; এই সংস্করণে কোনো inheritance rule যাচাই ও চালু করা হয়নি, তাই প্রতিটি কেস `UNSUPPORTED_CASE` হিসেবে ফেরত যায়, কোনো ভাগের হিসাব করে না।
* স্থানীয় গবেষণা ফল মুদ্রণ করুন; ব্রাউজারের Print থেকে PDF সংরক্ষণ করুন।

## যাচাই ও চালু করা

`node --test` দিয়ে built-in test চালান; `node server.mjs` দিয়ে সরাসরি সার্ভার শুরু হয়, তবে এতে admin import বন্ধ থাকে। Windows-এ admin import-সহ চালু করতে `run-local.cmd`-এ ডাবল-ক্লিক করুন।

এই repository-তে অ্যাপের source code রাখা যায়, কিন্তু GitHub Pages Node.js সার্ভার বা SQLite চালায় না। তাই শুধু GitHub Pages চালু করলেই সার্চ অ্যাপ অনলাইনে কাজ করবে না। এই সংস্করণ নিজের কম্পিউটারে চালান। সার্বজনীন অনলাইন চালনার জন্য আলাদা Node.js hosting, production database, নিরাপদ account-based admin authentication, HTTPS এবং উৎস-পাঠ্য reuse করার লিখিত অধিকার যাচাই প্রয়োজন।
