# সিরাজী ফারায়েজ গবেষণা সার্চ

বাংলা ও আরবি ভাষায় ফারায়েজের দলিল খোঁজার browser-only অ্যাপ। ব্যবহার করতে Node.js, npm বা কোনো সার্ভার লাগে না।

## ব্যবহার

লাইভ অ্যাপ: https://almuafydesign.github.io/siraji-faraid-search-engine/

প্রথমবার খুললেই repository-তে রাখা ব্যবহারকারী-প্রদত্ত সিরাজী দলিল সংকলনের ৪০টি উদ্ধৃতি এই ব্রাউজারে সূচিবদ্ধ হবে। অন্য ব্রাউজার বা ডিভাইসেও একই প্রাথমিক সংগ্রহ পাওয়া যাবে।

## প্রাথমিক সংগ্রহের সীমা

উদ্ধৃতিগুলো [আগের repository-তে থাকা siraji.json](https://github.com/AlmuafyDesign/al-muafy-faraid/blob/main/Almuafy%20Fi%20Halli%20siraji/data/siraji.json) থেকে রূপান্তর করা হয়েছে; মূল তথ্যসূত্র হিসেবে সেখানে User-provided الدليل.odt লেখা আছে। এতে ১১টি অধ্যায়ের ৪০টি ইবারত আছে। এটি পূর্ণ সিরাজী কিতাব বা মাকতাবাতুশ শামেলার সমগ্র পাঠ্য নয়। মুদ্রিত বই, সংস্করণ ও পৃষ্ঠার নির্ভরযোগ্য তথ্য নেই; row নম্বরকে পৃষ্ঠা ধরা হয়নি। প্রতিটি উদ্ধৃতি মানব-যাচাই বাকি হিসেবে চিহ্নিত।

## নিজের পাঠ্য আমদানি

কিতাব যোগ পাতায় অনুমতিপ্রাপ্ত JSON, TXT, Markdown, HTML বা XML ফাইল দিন। JSON-এ passages অ্যারে এবং প্রতিটি অনুচ্ছেদে original_text রাখুন। নতুন পাঠ্য এই ব্রাউজারের IndexedDB-তে থাকে; GitHub-এ যায় না। ব্যাকআপ নিয়ে অন্য ডিভাইসে পুনরুদ্ধার করা যাবে।

## গবেষণার সীমা

অনুসন্ধানের ফল চূড়ান্ত ফতোয়া নয়। ক্যালকুলেটরে এখন যাচাইকৃত হিসাবের নিয়ম নেই, তাই এটি ভাগ গণনা করে না। সার্চে পর্যাপ্ত দলিল না পেলে অনুমানভিত্তিক উত্তর দেওয়া হয় না।
